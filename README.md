## 常见问题

**E-Commerce VPS 和 Basic 的差价主要买到了什么？**
两样东西：更高的带宽（2.5Gbps 起步对 1Gbps）和更好的线路（特定机房 CN2 GIA 等中国优化线路对普通国际线路）。如果是面向大陆用户的业务，第二项的体感差距远大于参数差距，晚高峰尤其明显。

**SLA 系列的 99.99% 承诺怎么兑现？**
达不到时按 SLA 协议赔付服务时长，协议条款在官网单独公示。这个承诺目前只有洛杉矶 USCA_5 机房提供。

**一个月的流量不够用怎么办？**
同系列更高档位流量更大，官方页面也说明 VPS 可随时在机房间迁移；流量超出后的处理方式以服务条款为准，大流量业务建议直接按月流量上限选档，别按平均值估。

**Linux 基础一般，能用吗？**
搬瓦工是纯自助服务，没有托管运维。KiwiVM 面板把重装、换机房、换 IP 这类操作做成了按钮，但应用部署本身需要自己动手，或者自己找运维。

**多久能开通？**
官方标注 Instant setup，付款成功后系统自动开通，KiwiVM 面板登录信息会发到注册邮箱。
